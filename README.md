# Amd Pay Landing Page

صفحة هبوط احترافية لتطبيق أمد باي، جاهزة للنشر على Vercel أو Netlify.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## البناء للنشر

```bash
npm run build
```

## تعديل الروابط والصور والنصوص

افتح الملف:

```bash
src/siteConfig.js
```

ومن داخله تستطيع تغيير:
- رابط Google Play
- رابط واتساب
- فيسبوك وإنستقرام
- أرقام التواصل
- الشعار
- صور واجهات التطبيق
- النص الرئيسي والوصف

## أماكن الصور

- الشعار: `public/assets/amd-pay-logo.jpeg`
- صور التطبيق: `public/assets/screens/`

## النشر على Vercel

1. ارفع هذا المشروع إلى GitHub.
2. ادخل vercel.com.
3. اختر Add New Project.
4. اختر المشروع.
5. اضغط Deploy.
